## Para restaurar el carril

1. `git mv` de cada carpeta a su sitio original (`fundamentos/canto/`, `contexto/plan_estudio/`).
2. Devolver a `AGENTS.md`, `fundamentos/AGENTS.md` y `repertorio/AGENTS.md` lo que dice `reglas_archivadas.md`, por `nueva-regla` (los números F12, F15 y RP5 siguen libres).
3. Reponer el marcador de canto en `sistema/estado/estado_actual.md` y las filas de «Hoy».
